# Public Knowledge Base and Backlinks

## Canonical public destination

The only public project destination is [https://bdcmr.ai-aarti.com](https://bdcmr.ai-aarti.com). Public documentation, AI-readable context, and any future knowledge-base pages should link readers to that site where a project destination is appropriate.

## Publication boundary

The local development repository is not a public source of truth and must not be referenced by public artifacts, deployment configuration, package metadata, sitemap, robots file, AI-readable file, or public documentation.

The source Markdown in `/wiki` is a local knowledge-base draft set. If it is published through any documentation service, preserve its links to the canonical public site and do not expose the local repository URL.

## Editorial standard

Public pages must preserve the project’s research-only boundary. Do not imply validated clinical efficacy, patient-specific output, diagnosis, treatment recommendation, regulatory authorization, active hospital integration, or a public code repository without traceable evidence and explicit approval.
